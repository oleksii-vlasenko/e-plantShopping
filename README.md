# e-plantShopping

**e-plantShopping** is a React e-commerce storefront for Paradise Nursery, an online plant shop.

The app presents a landing page, a plant catalog, and a shopping cart so customers can browse plants and add them to the cart. State is managed with Redux Toolkit.

## Features

- Landing page with a brief introduction to Paradise Nursery
- Product list of plants grouped by category
- Shopping cart with quantity updates and item totals

## Getting started

```bash
npm install
npm run dev
```
